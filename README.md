- Play the Xbox 360 game show 1 vs 100 again on your modded Xbox 360.
- Play online on the community server, together with PC and Xbox One / Series players.
- Bring your own game files. This project ships no game content.

- Website: [1vs100.fans](https://1vs100.fans)

## Play

1. Download the zip from the [releases page](https://github.com/1vs100/1vs100-reborn-x360/releases).
2. Copy your game packages and the loader to the console.
3. Sign in on the first controller and start the loader.

The [Xbox 360 setup guide](https://docs.1vs100.fans/xbox-360/) walks you through each step, lists the game files and explains every error message.

## Development

The loader is a system DLL that connects the game to the community server instead of the retired Xbox LIVE service. Building it, its configuration and how a release is made are in [DEVELOPMENT.md](DEVELOPMENT.md). Pull requests: see [CONTRIBUTING.md](CONTRIBUTING.md).

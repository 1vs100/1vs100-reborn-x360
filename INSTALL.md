# Installing 1 vs 100 Reborn (Xbox 360)

The full guide, with the list of game files and every error message, is at https://docs.1vs100.fans/xbox-360/

## What you need

- An Xbox 360 that runs unsigned code (RGH or JTAG), with DashLaunch installed.
- The Avatar data on the console.
- Your own 1 vs 100 game files: the game, the launch package, and the show and episode packages.

## Steps

1. Check your game files against the file table at https://docs.1vs100.fans/game-files/
   Each file name is its content id, ending in `58`, with no extension.
2. Copy the game packages to `Hdd:\Content\0000000000000000\584A07D1\00000002\`
3. Create a folder such as `Hdd:\Games\1vs100Reborn`.
4. Copy `launcher.xex` into it and rename it to `default.xex`.
5. Copy `1vs100Reborn.xex` and `1vs100Reborn.ini` into the same folder. The `.ini` is already set for the community server.
6. Sign in with your profile on the first controller, then start `default.xex`.

If a message appears, or the game does not start, see https://docs.1vs100.fans/xbox-360/#if-something-goes-wrong
